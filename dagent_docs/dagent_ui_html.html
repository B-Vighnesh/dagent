The Investigation

Every page has
something to hide.

The Deception

Dark patterns are interface and copy tricks designed to steer you into decisions you never meant to make: hidden fees revealed only at checkout, subscriptions that are one click to join and a phone call to leave, buttons whose wording makes "no" feel like the wrong answer.

Most tools that go looking for this only check shopping carts. Dagent doesn't stop there. The same tactics show up outside e-commerce too: a streaming app's "10-day free trial, cancel anytime" that quietly auto-renews, a news site's newsletter popup that reappears no matter how many times you close it, a SaaS signup that buries the "continue without an account" option. They all get read the same way.

The Agent's Method

Dagent runs quietly in the background as you browse. Every scraped block of text is sentence-segmented and passed through a cascade of purpose-built classifiers, cheap enough to run continuously, precise enough to name the exact sentence and the exact tactic.

Nothing is flagged in bulk. Nothing is guessed. Every result comes back with a confidence score and a category, so you can see exactly why the page was flagged, not just that it was.

The Method

A two-stage
interrogation.

Every piece of text gets a fast first look, and only the suspicious ones get the full workup. That's what keeps Dagent quick enough to run on every page, every time.

01
Stage One

The Lookout

A lightweight binary classifier scans every sentence the instant it renders, fast enough to run continuously without you ever noticing it's there.

02
Stage Two

The Profiler

Anything the Lookout flags gets a second, closer read from a specialist model that names the exact tactic in play: scarcity, urgency, social proof, and the rest.

03
Stage Three

The Interrogator

The hardest, most ambiguous calls get escalated to a language model for a final read and a plain-English explanation, used sparingly, only when the first two stages aren't sure.

Agent Capabilities

What Dagent
actually does.

Real-Time Scanning

Flags manipulative text the moment a page loads, and again every time you scroll into new content.

Sentence-Level Precision

Points to the exact sentence responsible, with character offsets, not just "this page looks suspicious."

Two-Stage ML Pipeline

A binary filter and a category specialist working in cascade, so classification stays fast and cheap.

On-Page Highlighting

Draws attention to flagged text right where it lives on the page, with the tactic named beside it.

Adaptive Learning

Every issue you report helps retrain the agent on the cases it got wrong.

Offline Mode · In Progress

Currently in the works: an on-device build so detection runs fully offline and nothing about your browsing ever has to leave your machine.
